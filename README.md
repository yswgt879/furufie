# ポケコン PC-G850用ゲーム 『フル・フィー　Furu･Fie』

## 動作機種
SHARP PC-G850系

## 開発言語
ポケコン本体又はエミュレータ（以下本体と記す）内蔵のＣ言語・機械語<br>

## 同梱ファイル

| ファイル名  | 内容                                       |
|-------------|--------------------------------------------|
| `README.md` | マニュアルファイル                         |
| `extlib.h`  | Ｃ言語ソースファイル（拡張関数ライブラリ） |
| `furufie.c` | Ｃ言語ソースファイル（メイン）             |
| `data.hex`  | データファイル（Intel HEX形式）            |

## セットアップ

本体へ、以下の順でセットアップします。<br>

### PC-Gリンク以外の転送ソフトをお使いの場合

ソースリストに行番号が付いていませんので、ポケコンのSIO設定でLine Numberを"`no`"に変更してください。<br>

* BASICモードからMONで機械語モニタを起動し、`USER 063F`と入力してEnterキーを押し、機械語のユーザーエリアを確保します。<br>
その後、`R`と入力してEnterキーを押し、データファイル（`data.hex`）を転送します。
* `extlib.h`を転送し、同名でファイルを保存します。
* `furufie.c`を転送します。（※ファイルは保存しません）

### PC-Gリンクをお使いの場合

ソースリストをPC-Gリンクのウインドウで開いた時点で行番号が付きますので、ポケコンのSIO設定のLine Numberを変更する必要はありません。<br>

* BASICモードからMONで機械語モニタを起動し、`USER 063F`と入力してEnterキーを押し、機械語のユーザーエリアを確保します。<br>
* `data.hex`のファイル名を"`data.dat`"に変更します。<br>
その後、`R`と入力してEnterキーを押し、データファイル（`data.dat`）を転送します。
* `extlib.h`のファイル名を"`extlib.c`"に変更して転送し、"`extlib.h`"の名前でファイルを保存します。
* `furufie.c`を転送します。（※ファイルは保存しません）

※本体のRAM容量が標準（未改造・32KB）の場合、出来るだけ本体の容量を空けておいてください。（理由は後述）<br>

## ゲームのジャンル

パズルゲーム<br>

## 起動方法

本体の`SHIFT(2ndF)`+`TEXT`キーを押下し、本体内蔵のＣ言語を起動し、`Go`（`Gキー`を押下）でコンパイル及び起動します。<br>

## 操作方法

### 《タイトル画面》

| キー        | 役割                                                                                              |
|-------------|---------------------------------------------------------------------------------------------------|
| `8・2キー`  | ステージセレクト（1～20）（8:加算・2:減算）                                                       |
| `+・-キー`  | ゲームの速度調整（1～99）（+:速く・-:遅く）                                                       |
| `Sキー`     | 音のOFF/ONの切り替え<br> ※本体に圧電ブザーが取り付けられていない場合、ONにしても音は鳴りません。 |
| `SPACEキー` | ゲームスタート                                                                                    |

### 《ゲーム》

| キー                       | 役割                                                               |
|----------------------------|--------------------------------------------------------------------|
| `８`・`２`・`４`・`６キー` | 上下左右へ移動                                                     |
| `SPACEキー`                | ブロックを押す（滑らせる）、ブロックを壊す、各種メッセージスキップ |
| `Gキー`                    | ギブアップ                                                         |

## 遊び方

らむ君を操作し、全ての果実（さくらんぼ・苺・バナナ・オレンジ・林檎・葡萄・桃・パイナップル・メロン）を取ってください。<br>

らむ君は、上下左右に移動できます。<br>
但し、壁やブロック（上下左右）は通り抜けられません。<br>

ブロックは、矢印と向かい合わせ以外の方向から押すと、矢印の方向へ物があるところまで滑らせることができます。<br>
（例）上矢印の場合、後ろ・左・右から押すと、上方向へ物があるところまで滑ります。<br>

ブロックの方向に物があって動かせない場合、矢印の後ろから押すと壊すことができます。<br>
但し、ブロックの方向に、対の方向のブロックがある場合は壊せません。<br>
（例）上矢印の場合、後ろから押すと壊せますが、上矢印の上側に、下矢印のブロックがある場合は壊せません。<br>

らむ君が移動できなくなった場合や解けなくなった場合は、ギブアップでやり直ししてください。<br>

ギブアップを３回すると、ゲームオーバーとなります。<br>

全部で２０ステージまで用意してあります。<br>
２０ステージ目をクリアすると、エンディングとなります。<br>

## 終了方法

本体の`ON(BREAK)キー`や`OFFキー`を押してください。<br>

## うまくコンパイル・動作しない場合

このゲームでは、本体内蔵のＣ言語を使用している都合上、本体の残りRAM容量は充分余裕を取る必要があります。<br>

コンパイルが通らない場合や、ゲーム動作中に異常終了してしまう場合、このゲーム以外のファイルを削除してください。<br>
また、機械語のユーザーエリアも確保しないでください。<br>
（機械語モニタから「`USER 00FF`」を実行）<br>

## データファイルについて

データファイル（`data.hex`）は、以下の構成となります。<br>

データ：Intel HEX形式<br>
０１～１０行　データレコード　ドット絵データ<br>
１１～１６行　データレコード　サウンドデータ<br>
１７～８４行　データレコード　ステージデータ<br>
８５行　　　　エンドレコード<br>

※データレコードの後ろ２桁は、チェックサムとなっており、レコード行のデータ内容をもとに算出された情報が格納されております。<br>
データ内容を変更する場合、チェックサムも計算して変更する必要があります。<br>

Excelで作成した簡易的なステージエディタやドットエディタを、別途用意してあります。<br>
このエディタで作成した内容から、チェックサムを自動計算の上、上記データファイル（`data.hex`）として出力することが可能です。<br>
ご希望の方は、X（旧Twitter）にてフォローの上、DMをお願い致します。<br>
（※恐れ入りますが、フォロー無しでお受けすることはできません）<br>
